# System Design Interview Preparation

This project contains notes and examples for low-level design, high-level design, SOLID principles, design patterns, and revision.

- `01-LLD/`: OOP fundamentals, UML, LLD concepts, and design problems
- `02-HLD/`: fundamentals, networking, databases, distributed systems, and microservices
- `03-SOLID/`: SOLID principles and interview questions
- `04-Design-Patterns/`: creational, structural, and behavioral patterns
- `05-Revision/`: cheat sheets and interview checklists

For each topic, maintain requirements, notes, Java code, trade-offs, and interview questions as relevant.
