# LC 56 — Merge Intervals

**Pattern:** Sorting + Intervals (Merge Overlapping Intervals)

**Problem:** [LeetCode 56 — Merge Intervals](https://leetcode.com/problems/merge-intervals/)

**Status:** SOLVED

## 1. Question (write in your own words)

Given a list of intervals, combine all overlapping intervals and return a list of non-overlapping intervals.

## 2. Input / Output & Boundary Cases

**Input:**
`[[1,3], [2,6], [8,10], [15,18]]`

**Output:**
`[[1,6], [8,10], [15,18]]`

**Boundary cases:**
- Empty array
- Single interval
- No overlapping intervals
- One interval completely inside another
- Intervals touching at an endpoint, such as `[1,4]` and `[4,5]`

## 3. Recognition Keywords and Intuition

**Keywords:** Intervals, overlap, merge, sorting.

**Intuition:**

If we sort all intervals by starting position, overlapping intervals become easier to identify.

Compare every interval with the last interval already added to the result.

**Important conditions:**
- `current.start <= previous.end` → Merge
- `current.start > previous.end` → Add separately

**Revision trigger:** Sort → Compare → Merge or Append.

## 4. Approach 1 — Brute Force

**Idea:** Repeatedly compare intervals and merge overlapping pairs until no overlaps remain.

**Pseudocode:**

```text
Repeat until no changes:
    Compare interval pairs

    If two intervals overlap:
        Merge them
        Remove the redundant interval

Return resulting intervals
```

**Time complexity:** O(n³) for a straightforward repeated-scan implementation.

**Space complexity:** O(n) if using a separate working list.

## 5. Approach 2 — Optimized

**Idea:** Sort intervals by start, then merge in one pass.

**Invariant / Proof:**

After processing each interval, the result contains correctly merged intervals for everything processed so far.

Because intervals are sorted by start, the current interval only needs to be compared with the last merged interval.

**Pseudocode:**

```text
Sort intervals by start

result = []

For each interval:
    If result is empty:
        Add interval

    Else if current.start > previous.end:
        Add interval

    Else:
        previous.end =
            max(previous.end, current.end)

Return result
```

**Time complexity:** O(n log n) for sorting plus O(n) for scanning.

**Space complexity:** O(n) for the result, excluding sorting implementation details.
